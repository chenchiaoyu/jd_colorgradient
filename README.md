## 📖 簡易使用說明書 (User Manual)

### 1. 漸層與色彩生成器 (Gradient Studio)
* **主色與次色設定**：自由挑選品牌色系（如 Rose 玫瑰、Violet 紫羅蘭、Teal 湖水綠等）及其深淺調性（Tint 柔和底色、Soft 柔光、Vibrant 鮮明等）。
* **漸層模式**：支援 **線性漸層 (Linear)**、**放射漸層 (Radial)** 與 **錐形漸層 (Conic)**，並可自由調整角度與中心百分比。
* **CSS 一鍵複製**：點擊預覽畫面上的按鈕或色碼區塊，即可瞬間複製完整的 `background` CSS 語法，無縫應用於網頁專案中。

### 2. 即時預覽與文字搭配 (Live Preview & Typography)
* **文字與漸層搭配預覽**：在預覽畫面上直接檢視文字在自訂漸層背景上的視覺效果。
* **字體風格切換**：支援切換 **思源宋體 (Noto Serif TC)** 與 **思源黑體 (Noto Sans TC)**。
* **字體大小調整**：提供 **小、標準、中、大、特大、巨大** 六段式字級快捷切換。
* **文字色彩基準**：提供「品牌主色與灰階」（Gray 900、Gray 700、Rose 系列）與「輔助色 Deep」（紫羅蘭、天空、湖水、青苔、草木、大地等）共多種專業色彩對比選項。
